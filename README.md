# 🎲 Dice Game (Python)

A simple and fun command-line dice game built with Python. This project demonstrates the use of Python fundamentals such as loops, functions, conditionals, random number generation, and user input handling.

## 📌 Features

* Roll virtual dice using Python
* Random dice number generation
* Multiplayer or single-player gameplay (if applicable)
* Score tracking
* Easy-to-understand code structure
* Beginner-friendly project

## 🛠️ Technologies Used

* Python 3
* `random` module

## 📂 Project Structure

```bash
dice-game/
│
├── main.py          # Main game file
├── README.md        # Project documentation

```

## ▶️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/dice-game.git
```

2. Navigate into the project folder:

```bash
cd dice-game
```

3. Run the Python file:

```bash
python main.py
```

## 🎮 How to Play

1. Start the game.
2. Each player rolls the dice.
3. The program generates a random number between 1 and 6.
4. Scores are calculated based on the game rules.
5. The player with the highest score wins.
